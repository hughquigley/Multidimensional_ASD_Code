# Multidimensional_ASD_Code\

This repo contains the main code sources for this project, due to the dataset being private I am only able to provide the code to be looked at. \
GMM - Gaussian Mixture model code\
Factor_analysis -  Factor analysis code \
VAE - Variational Auto-Encoder code \
Person_export_VAE - contains work with the radar plots, 2D representations, 2D Diptest and other valdiation and figure creations based on the other code\
diptest_ASD - Contains all of the 4D diptest, clustering and interpratation work\
